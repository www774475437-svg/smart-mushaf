# المصحف الذكي

تطبيق مصحف لأندرويد: مصحف المدينة برواية حفص بصفحاته، مع التلاوات والتفاسير والحفظ والتسميع.

## الميزات
- قراءة بتقليب الصفحات أو بالتمرير العمودي، مع تمرير تلقائي تتحكم في سرعته.
- الوضع النهاري والورقي والليلي، وحجم الخط، وإطار الصفحة (من الإعدادات).
- الضغط المطوّل على أي آية: تشغيل من هنا، من آية إلى آية، تكرار، علامة، تظليل، نسخ بتشكيل وبدونه، مشاركة نصًّا أو صورة، تسميع، والتفسير مع الاستماع إليه ونسخه ومشاركته.
- القرّاء: أكثر من ٣٠ قارئًا آية بآية مع تظليل الآية، وجميع قرّاء MP3Quran بالسور الكاملة، وإضافة قارئ برابط، وتحميل السور للاستماع بدون إنترنت.
- التفاسير: الميسر والجلالين مدمجان، والسعدي وابن كثير والطبري والبغوي والقرطبي والوسيط بالإنترنت أو بالتحميل.
- الحفظ والتسميع: تسميع بالصوت يكتشف الكلمات الخاطئة، واختبار الإخفاء، وقائمة «أخطائي»، وتعليم السور المحفوظة.
- الختمة بورد يومي، والبحث في القرآن والتفسير، والروايات (ورش، قالون وغيرها) من الإعدادات.

## البناء
يُبنى ملف APK تلقائيًا في GitHub Actions عند كل تحديث، ويُنشر في صفحة Releases.
